# 有料パイロット リリース判定

判定日: 2026-09-06
対象: `https://enkiseojp.com/` / 手動・単発の「30日SEO改善スタート診断」

## 判定

**条件付き GO（先着5社の低ボリューム手動パイロットのみ）**

コード、表示、公開デモ、URL診断、法務ページ、API境界、回帰テストはパイロット用に整合した。セルフサービスSaaS、継続運用契約、大量集客向けの一般公開APIとしてはリリースしない。

公開前に、運営者本人が下記の外部確認を完了すること。

- 特商法ページの運営者名、住所の開示方法、電話番号、事業形態、適格請求書・税務上の表記を専門家または所管窓口と確認する。
- Vercelのサーバー側に `PILOT_ACCESS_SIGNING_SECRET` と正確な `APP_ALLOWED_ORIGIN` を設定し、ブラウザへ秘密を渡さない。
- GSCを使う場合は対象プロパティと一致する期限・用途限定トークンを運営者だけが発行し、閲覧専用権限で扱う。
- 手動の申込み確認、請求、入金確認、納品前キャンセル、納品記録、データ削除依頼の運用手順を確定する。
- 「先着5社」の受付数を実数で管理し、枠終了後は表示を更新する。契約前に利用可能な支払方法を具体的に通知する。
- 本番デプロイ後に `/api/health`、`/app/audit`、メールリンク、利用規約、プライバシー、特商法表記、canonical、robots、sitemapを再確認する。

## 完了した範囲

- 名称を「日本向けSEO運用アシスタント／SEO運用アシスタント」に統一。
- 先着5社 ¥9,800（税込）、標準 ¥19,800（税込）、単発、7営業日以内、納品前全額返金、納品後は成果理由の返金なしに統一。
- 50ページ超、多拠点、EC、詳細競合分析は個別見積もりと明示。
- 納品物、除外事項、順位・流入・売上の非保証、デモ／実測／簡易判定を分離。
- LPを安全なデモ → 自社検証 → 納品範囲 → 手順 → 価格 → 信頼 → FAQの順に整理。
- Google SEO、Yahoo! JAPAN、GEOを別セクションとして表示。Yahoo順位とAI可視性は未計測のまま明示。
- 公開URL診断に入力制限、プライベート宛先拒否、DNS解決後のIP固定接続、リダイレクト再検証、サイズ・時間・回数制限を実装。
- 生成、GSC、インデックス、SERP APIを署名付きスコープトークンで保護。GSCは対象プロパティにも束縛。
- AI上流失敗時の偽テンプレート補完を廃止し、明示的な失敗へ変更。
- ブログの旧ブランド／旧月額訴求を除去。未検証の体験談マーカーを含む行は公開ビルドから除外。
- 利用規約、プライバシー、特商法、セキュリティヘッダー、CI、ヘルスチェックを追加・更新。

## 検証結果

- `npm run check`: 5ファイル・53テスト成功、TypeScript成功、production build成功（ブログ・sitemap等81ファイル生成）。
- `npm audit --audit-level=high`: 既知の脆弱性 0。
- `deno check supabase/functions/server.ts`: 成功。
- `git diff --check`: 成功。
- Chrome表示確認: 1280×757 と 390×844 でLPを確認。モバイルCTAの切れを修正。
- 実URL E2E: `https://enkiseojp.com/` を公開HTMLとして取得し、HTTP 200、リダイレクト0、sitemap候補あり。Google 11項目、Yahoo未接続、GEO 5項目を分離表示。サイトへの変更操作なし。

## 自社SEOの証拠に関する結論

保存済みGSCでは90日間に5クリック、1,990表示、CTR 0.3%、平均掲載順位53.2、170クエリ、48インデックス済み／7未登録。Yahoo! JAPANの保存実測では一部の狭いクエリで前10入りが確認できる。一方、比較可能な前期GSC、問い合わせ、売上、施策単独の因果証拠はないため、「一部のニッチ意図で露出・上位表示が発生した」以上の成功主張はしない。詳細は `docs/seo-outcome-evidence.md` を参照。

## スケール前に必要な追加実装

- サーバーレスのインスタンス内メモリではなく、共有ストアを使う分散レート制限。
- 顧客ごとのGSC認証情報・プロパティを分離するテナント管理。
- エラー監視、監査ログ、保持期間に基づく削除ジョブ、障害時の運用手順。
- 本番環境での定期的なE2Eとセキュリティ回帰確認。
