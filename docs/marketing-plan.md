# 「30日SEO改善スタート診断」マーケティング実行計画

更新日: 2026-09-06
対象: 手動・単発の有料パイロット。セルフサービスSaaSや月額契約の販売計画ではない。

## 1. ポジショニング

表示名は「日本向けSEO運用アシスタント」。提供する商品は「30日SEO改善スタート診断」。

> 検索からの問い合わせを増やすために、次の30日でやることを整理します。

Google Search Consoleと公開情報をもとに、優先順位つきの改善リストとコンテンツ計画を、人が確認して納品する。順位上昇、アクセス、問い合わせ、売上は保証しない。

### 最初の顧客像

- 日本国内の地域サービス系中小企業
- 5〜50ページ程度のWordPressサイト
- Search Consoleを導入済み
- 専任のWeb・SEO担当者がいない
- 記事量産より「何から直すか」に困っている

医療・金融・法律など高リスクなYMYL領域は、品質・監修体制が整うまで初期対象から外す。

## 2. 商品設計

### 納品物

1. 閲覧専用GSCと公開ページによるインデックス・順位・流入課題の診断
2. 影響・原因・対応・作業量を添えた優先Top 10
3. 日本語キーワード候補と2〜3サイトの競合差分
4. 30日間の既存ページ改善・コンテンツ計画
5. 30分のオンライン説明

含まないもの: 記事の大量作成、サイトのコード変更、リンク購入、順位・流入・問い合わせ・売上の保証。

### 価格と条件

- 先着5社: 9,800円（税込・単発）
- 標準価格: 19,800円（税込・単発）
- 50ページ超、複数拠点、EC、詳細な競合分析: 個別見積もり
- 原則納期: 支払いと必要情報の確認後7営業日以内
- 返金: 診断レポート納品前は全額返金。納品後は保証していない成果を理由とする返金には対応しない

将来の月額支援は「診断後に実装支援への需要があるか」という検証仮説に留め、現時点では販売・決済しない。

## 3. 獲得チャネル

1. **WordPress制作会社・地域のWeb制作会社**: 納品後のSEO相談を補完する白ラベル不可・紹介型の提携候補。顧客のIDやパスワードを受け取らない運用を強調する。
2. **Lancers**: 小さな単発診断として提示し、価格・範囲・納期・修正条件を明記する。プラットフォームのルールに従う。
3. **商工会議所・創業支援窓口**: セミナー営業ではなく「自社サイトの検索課題を30日計画にする」実務テーマで情報提供を打診する。
4. **紹介**: 税理士、制作会社、広告運用者など中小企業支援者からの紹介。紹介料を設ける場合は事前に条件を文書化する。
5. **自社コンテンツ・小規模ウェビナー**: Search Consoleの見方と優先順位付けに絞り、記事量産や順位保証を訴求しない。

## 4. 14日間の実験スケジュール

以下は市場予測ではなく、初回実験の行動・検証目標。

| 日 | 実施内容 | 完了条件 |
|---|---|---|
| 1 | LP、利用規約、プライバシー、特商法、サンプルレポートを整合確認 | 価格・範囲・返金・非保証が一致 |
| 2 | 地域サービス系候補を5社抽出 | URL、業種、選定理由だけを記録 |
| 3 | WordPress制作会社を5社抽出 | 紹介先との適合理由を1行記録 |
| 4 | 候補10社の公開サイトを個別確認 | 各社に具体的な気づき1件 |
| 5 | 5社へ個別連絡 | 一斉送信しない |
| 6 | 残り5社へ個別連絡 | 合計10社 |
| 7 | 返信・拒否理由を整理 | コピー改善点を3件以内に集約 |
| 8 | コンテンツ1本目を公開 | 下記タイトル1 |
| 9 | 返信先と15〜30分面談 | 同意なくGSC権限を求めない |
| 10 | 希望者に匿名サンプルレポートを提示 | 実顧客データを含めない |
| 11 | コンテンツ2本目を公開 | 下記タイトル2 |
| 12 | 制作会社へ提携案を再提案 | 紹介時の役割分担を明確化 |
| 13 | コンテンツ3本目または30分ミニ説明会 | 質問と不安を記録 |
| 14 | ファネル集計・継続判断 | 仮説、結果、次の変更を記録 |

実験目標: 個別候補10社、返信または面談3件、サンプルレポート希望2件、有料パイロット1〜2件。

## 5. 初期コンテンツ案

1. 「Search Consoleで『表示されているのに問い合わせにつながらないページ』を見つける3つの見方」
2. 「SEOで最初の30日にやること: 5〜50ページの中小企業サイト向け優先順位」
3. 「SEO会社に依頼する前に整理したい、改善項目の影響・原因・作業量」

各記事のCTAは「まずは無料で対象サイトを確認する」。無料診断や順位改善を約束する表現は使わない。

## 6. アウトリーチ文面

### 地域事業者向け

件名: 貴社サイトのSEO改善順について1点だけご相談

> 突然のご連絡失礼いたします。公開ページを拝見し、検索からの問い合わせを増やすうえで、まず確認するとよさそうな点が1つありご連絡しました。現在、Search Consoleと公開情報をもとに「次の30日で着手する順番」をまとめる単発診断を、先着5社9,800円（税込）でご案内しています。順位や売上を保証するものではなく、ID・パスワードもお預かりしません。対象になるかだけ無料で確認できますので、ご関心があればサイトURLをご返信ください。不要でしたらご返信は不要です。

### WordPress制作会社向け

件名: 納品後のSEO相談を30日計画に整理する連携のご相談

> はじめまして。5〜50ページ程度のWordPressサイトを対象に、Search Consoleと公開情報から改善優先Top 10と30日計画を作る単発診断を提供しています。制作会社様の改修作業を奪うのではなく、顧客から届く「SEOは何から直すべきか」を整理し、必要な実装を制作会社様へ戻す紹介型の連携を想定しています。閲覧専用権限だけを使用し、ID・パスワードは受け取りません。匿名サンプルをご覧いただき、合わなければそこで終了できます。

## 7. ファネル計測

| 段階 | 指標 | 初回目標 |
|---|---|---:|
| 接触 | 個別に調査して送った候補数 | 10 |
| 関心 | 返信または面談 | 3 |
| 評価 | サンプルレポート希望 | 2 |
| 購入 | 有料パイロット | 1〜2 |
| 提供品質 | 期限内納品率 | 100% |
| 学習 | 不採用理由を記録できた件数 | 返信全件 |

母数が小さいため転換率を市場一般値として扱わない。個人情報を含む営業リストを公開デモやリポジトリに保存しない。

## 8. 信頼・プライバシー境界

- Search Consoleは閲覧専用権限だけを依頼し、診断後は顧客自身がいつでも削除できる
- Googleアカウント、CMS、サーバーのID・パスワード、決済情報は受け取らない
- 公開デモはサンプルであり、入力内容はブラウザ内にのみ保存されると明示する
- 外部生成・SERP機能を使う場合は、送信される情報と処理事業者をプライバシーポリシーに明記する
- 事例公開、画面共有、引用は個別に明示同意を得る。架空の導入実績や推薦文を使わない
- 大量記事、リンク購入、隠しテキスト等、Googleのスパムポリシーに反する施策を提案しない
