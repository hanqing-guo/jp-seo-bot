# enkiseojp.com SEO 成果エビデンス監査

最終確認: 2026-09-06 (JST)

## 結論

これまでの SEO 作業には、**Google に多数のページが認識され、一部の狭いクエリで検索上位を取った証拠**があります。一方、同条件の GSC 前期値がないため収録数の増加率は確定できず、問い合わせ・売上につながる継続的な流入改善を証明する材料もまだありません。現時点の判定は「技術的な露出と一部クエリの順位には成果あり、事業成果と再現性は未証明」です。

Claude Code 等で作業したこと自体、記事数、ヒューリスティック難易度、デモ順位は成果として数えていません。

## 確認できた成果

### 1. Google Search Console の 2026-08-28 実測

リポジトリに保存された Search Console UI の読み取り記録では、2026-06-02〜08-25 の 90 日について次の値が確認されています。

| 指標 | 実測値 | 読み方 |
|---|---:|---|
| インデックス済み | 48 ページ | Google に収録されたページは存在し、技術的な露出は進んだ |
| 未インデックス | 7 ページ | `noindex` 1、検出済み未登録 4、クロール済み未登録 2 |
| クリック | 5 | 流入は発生したが、事業成果を論じられる規模ではない |
| 表示回数 | 1,990 | 検索結果での露出は発生している |
| CTR | 0.3% | 改善余地が大きい |
| 平均掲載順位 | 53.2 位 | サイト全体として上位獲得には至っていない |
| 計測クエリ | 170 | Google が複数テーマとの関連を認識している |

ただし、この 90 日集計より前の同条件の GSC 数値が保存されていないため、クリック・表示回数・平均掲載順位の「改善率」は計算できません。また、2026-08-27〜28 の内容修正は集計終了日の後であり、このデータからその効果を主張できません。

### 2. 一部の狭いクエリで上位表示

保存済みの Yahoo! JAPAN 実測では、2026-08-26 に 2 つの着地ページ・3 クエリ文字列が前 10 入りしていました（`DeepSeek SEO 記事` と `DeepSeek SEO 記事 作成` は同じ記事への表記違い）。09-02 と 09-04 には前 10 入りが 4 クエリ文字列となり、09-04 時点では `DeepSeek SEO 記事`、`DeepSeek SEO 記事 作成`、`日本語SEO記事 自動生成` が 1 位、`seo bot` が 4 位と記録されています。

これはクエリ単位の成果ですが、次の制約があります。

- 09-04 は Yahoo! 単独測定で、Google Search Console のクリック増加と照合されていない。
- `seo bot` は 09-02 の 1 位から 09-04 の 4 位へ変動しており、順位は安定した成果とはまだ言えない。
- 旧監視 8 語は 7 週間半・4 回の実測で一度も前 10 に入らず、広いテーマでの再現性は確認できない。
- Yahoo! と Google の順位が食い違った事例があり、Yahoo! の結果を Google 順位として扱えない。

したがって「一部のニッチな検索意図でページが上位に出た」は言えますが、「SEO 全体が成功した」「流入や問い合わせが増えた」は言えません。

## 現在の公開サイトから確認できること

2026-09-06 の読み取り専用確認では、`https://enkiseojp.com/` は HTTP 200、canonical は同 URL、`robots.txt` はクロールを許可し、サイトマップには重複のない 80 URL がありました。公開・発見可能な URL は増えています。

これは現在の配信・クロール可能性の確認であって、80 URL が Google に収録されている証拠ではありません。最新の GSC 実測は 08-28 の 48 ページであり、その後サイトマップが 80 URL になった現在、収録率と増減は未確認です。

## 活動であって成果とは数えないもの

- 記事作成数、サイトマップ URL 数、構造化データ追加、技術修正のコミット。
- アプリ内のキーワード難易度。語彙ベースのヒューリスティックで、実 SERP の難易度ではない。
- アプリ初期値の順位履歴。`src/lib/seedData.ts` で生成されるサンプルで、実測履歴ではない。
- `site:` 検索の概算件数。4→70→52→120→64 と大きく変動しており、保存済みレポート自身も指標として不採用にしている。
- 自動レポートが正常終了した回数。監視処理の活動量であり、検索成果ではない。

## 効果判定に不足しているデータ

次回は Search Console から比較可能な 2 期間（例: 直近 28 日と前の 28 日）を、国=`Japan` でエクスポートする必要があります。

最低限必要な項目:

1. 全体のクリック、表示回数、CTR、平均掲載順位。
2. クエリ別およびページ別の同 4 指標と増減。
3. ページのインデックス登録レポートの現在値と、未登録 URL・理由。
4. 上位候補 4 語の Google 側の日次または週次推移。
5. 問い合わせ完了などのコンバージョン数。個人情報を含まない集計値でよい。

安全な取得方法は、所有者が GSC UI から CSV を書き出して共有するか、対象プロパティに閲覧専用権限を付与することです。ID・パスワード、サービスアカウント鍵、API シークレットをチャットやフォームに入力しないでください。
