# 日本向けSEO運用アシスタント

公式サイト: <https://enkiseojp.com/>

日本の中小企業向けに、Google Search Consoleと公開情報をもとにSEO改善の優先順位を整理するプロジェクトです。現在販売するのは、自動更新のSaaSではなく、人が確認して納品する単発の「30日SEO改善スタート診断」です。

## 現在の提供範囲

- GSCと公開ページによるインデックス・順位・流入課題の診断
- 影響・原因・対応・作業量を添えた優先Top 10
- 日本語キーワード候補と2〜3サイトの競合差分
- 30日間のページ改善・コンテンツ計画
- 30分のオンライン説明

先着5社は9,800円（税込・単発）、標準価格は19,800円（税込・単発）です。50ページ超、複数拠点、ECサイト、詳細な競合分析は個別見積もりです。記事の大量作成、コード変更、リンク購入、順位・流入・問い合わせ・売上の保証は含みません。

## 公開デモ

`/app` はログイン不要の説明用デモです。

- 初期キーワード、難易度、順位、タスクはサンプルデータ
- 追加データと下書きはブラウザの `localStorage` にのみ保存
- 難易度はキーワード文字列に基づくヒューリスティック推定
- SERP実測はDataForSEOがサーバー側で設定・保護されている場合のみ利用可能
- 記事下書きは生成APIが未接続の場合、明示されたテンプレートプレビュー
- GSC由来の数値は、保護されたサーバー側連携が有効な場合のみ実データ

デモに機密情報、ログイン情報、個人情報を入力しないでください。デモ操作は申込みや有料契約にはなりません。

## ローカル開発

```bash
npm ci
npm run dev
```

```bash
npm run typecheck
npm test
npm run build
```

Vite開発サーバーは通常 <http://localhost:5173> で起動します。生成物は `dist/` です。

## 主な構成

- `index.html` — 診断サービスのランディングページ
- `app.html`, `src/` — サンプルデモ
- `api/` — Vercel Functions
- `public/privacy/`, `public/terms/`, `public/tokushoho/` — 法務ページ
- `docs/marketing-plan.md` — 有料パイロットのマーケティング実行計画
- `db/migrations/` — 将来用のデータモデル案。本番顧客データの永続化が実装済みであることを意味しません

## 本番化に残る外部要件

セルフサービス販売には、ユーザー認証、テナント分離、永続ストレージ、請求・権限管理、運用監視が必要です。現在の実装はこれらを備えたSaaSとして販売できる状態ではありません。秘密情報を `VITE_*` に置かないでください。
